Privacy

PulseBridge is a demo of a personal health record. There are no accounts: nothing asks who you are. This note says what the demo does with data about your visit, and whose health data it shows.

Whose health data you see

The heart-rate readings are the real data of the person who runs this deployment, from their own watch, shown in public by their choice (a test deployment shows invented readings instead). Only the last 7 days are shown; older readings are kept, not shown. The blood-pressure readings come from a simulated cuff.

A cuff reading you send, and a reading you share with the test clinic, is kept in the record and shown to other visitors for the next 7 days. Send made-up numbers only.

The bot check (Google reCAPTCHA)

The start page loads Google's reCAPTCHA script (part of Google Cloud Fraud Defense) as soon as it opens, before you select "View the live demo". The script runs in your browser and talks to Google directly: it judges whether a person or a program is using the page and gives the page a one-time token. When you select the button, this site's server sends that token to Google, with the site's key and the action name, and gets back a score from 0.0 (likely a program) to 1.0 (likely a person). The server does not send Google your IP address or your browser's details. This page loads nothing from Google.

For this data the site's owner is the data controller and Google is the data processor: since 2 April 2026 Google processes reCAPTCHA data only on the owner's behalf, for security and abuse prevention, under the Google Cloud Terms of Service and the Cloud Data Processing Addendum.

Cookies

  • __session, set by this site when the bot check lets you in: a signed session identifier and its expiry time, nothing about you. Your browser sends it only to this site's server, and scripts on the page cannot read it. It lasts 24 hours, or until you select "Log out".
  • _GRECAPTCHA, set by Google's reCAPTCHA script. Google describes it as "a necessary cookie" for "providing its risk analysis".

This site sets no other cookie, and it has no analytics and no advertising. Google's reCAPTCHA script talks to www.google.com, so those requests can also carry cookies Google had already set on google.com, for example if you are signed in to a Google account.

Logs

Google Cloud Run, which runs this site's server, logs every request the page makes to it: the time, the address requested, the answer's status, size and duration, your browser's user agent, and the network address the request came from. The server's own log records each bot check's outcome and score, without your address; when it refuses requests for coming too fast or from another website, it notes the client IP address of the first such refusal of each kind from an address in a minute. Neither log records the cookie or any token.

Logs are kept for 30 days, Google Cloud Logging's default, which this project does not change, and are then deleted. The page itself is served by Firebase Hosting, which sends no request logs to this project unless its owner turns that on.

Not a medical service

This is a portfolio demo. Nothing it shows is medical advice, and the test clinic is not a real one.
